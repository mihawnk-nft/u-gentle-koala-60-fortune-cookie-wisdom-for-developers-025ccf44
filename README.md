## What it does

`main.py` writes one original fortune-cookie line for a software developer
to `/output/entry.txt`:

> The legacy code you curse today was written by someone who once felt as clever as you do now.

93 characters — inside the 1–120 character gate.

## Why this line

It reads like a real fortune cookie (one short balanced sentence), says
something true about a developer's day (cursing legacy code), and turns it
with a quiet twist that rewards a second read: the person who wrote that
code once felt exactly as clever as you do now — so the next reader of
*your* code may feel the same about you.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python standard library — no dependencies, no network access.
